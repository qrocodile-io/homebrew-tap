# homebrew-tap

Homebrew tap for [QRocodile CLI](https://github.com/qrocodile-io/qrocodile-cli).

```
brew tap qrocodile-io/tap
brew install qrocodile
```

Formulas in `Formula/` are published here automatically by `qrocodile-cli`'s release workflow (via [GoReleaser](https://goreleaser.com)) — don't edit them by hand.
